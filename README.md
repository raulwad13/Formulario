# DinoMaster — formulario de registro 🦖

Ejercicio de HTML, CSS y JavaScript para practicar formularios y validación en el navegador.

## Funcionalidades
- Campos de nombre, apellidos, edad, correo y contraseña.
- Selección de equipo dinosaurio y preferencias.
- Comprobación de campos obligatorios y coincidencia de contraseñas.
- Mensajes de validación sin recargar la página.

## Ejecutar
Abre `index.html` en tu navegador. No necesitas instalar paquetes.

## Importante
**Es una demostración de frontend.** No crea cuentas, no envía información ni almacena contraseñas. Para un registro real sería necesario un backend seguro.
